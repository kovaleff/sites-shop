# Quickstart: Публичная главная страница с каталогом сайтов

**Feature**: `003-catalog-home-page` | **Date**: 2026-10-28

Руководство по запуску и проверке фичи. Реализация описана в `tasks.md` (создаётся `/speckit.tasks`); здесь — только команды, сценарии и ожидаемые результаты.

Ссылки на детали: [spec.md](./spec.md) · [plan.md](./plan.md) · [data-model.md](./data-model.md) · [contracts/catalog-data-contract.md](./contracts/catalog-data-contract.md) · [contracts/ui-contract.md](./contracts/ui-contract.md)

## 1. Предварительные требования

| Требование | Проверка | Ожидаемо |
|---|---|---|
| PHP 8.3+ | `php -v` | `PHP 8.3.x` |
| Composer-зависимости | `composer install` | без ошибок |
| Node.js 22+ | `node -v` | `v22.x` или выше |
| Зависимости фронтенда | `npm install` | без ошибок |
| `.env` и ключ приложения | `php artisan key:generate` | `APP_KEY` заполнен |
| База данных (нужна Laravel и Orchid) | `php artisan migrate` | миграции применены |

Фича не требует новых миграций и сидов: данные каталога — фикстуры фронтенда.

## 2. Установка фронтенд-зависимостей (однократно)

```bash
npm install vue@^3.5 vue-router@^4.6 pinia@^3.0
npm install -D @vitejs/plugin-vue@^6.0 vitest@^5 @vue/test-utils@^2.5 jsdom@^30
npx shadcn-vue@latest add button card slider switch label badge skeleton pagination toggle-group avatar dropdown-menu sheet separator alert sonner tooltip
```

Проверка результата:

```bash
ls resources/js/components/ui        # каталоги компонентов shadcn-vue
ls resources/js/lib/utils.js        # cn() без TypeScript
grep -r 'lang="ts"' resources/js | wc -l   # ожидаем 0
```

Ожидаемо: компоненты сгенерированы в JS-варианте, `components.json` содержит `"typescript": false`.

## 3. Запуск

### Вариант A — единая команда Laravel

```bash
composer run dev
```

Запускает сервер, очередь и Vite в одном процессе.

### Вариант B — раздельно

```bash
php artisan serve            # http://127.0.0.1:8000
npm run dev                  # Vite dev-сервер с HMR
```

### Production-сборка

```bash
npm run build
php artisan route:list --path=how-it-works
```

Ожидаемо: сборка завершается без ошибок; в `public/build/manifest.json` присутствуют `resources/js/app.js` и `resources/css/app.css`.

Если интерфейс не обновился или появляется «Unable to locate file in Vite manifest» — выполните `npm run build` (или перезапустите `npm run dev`).

## 5. Сценарии мок-данных

Переключение — через `localStorage` в консоли браузера, затем перезагрузка страницы:

```js
// обычная выдача
localStorage.removeItem('catalog:mock-scenario')

// пустой каталог
localStorage.setItem('catalog:mock-scenario', 'empty')

// ошибка загрузки списка
localStorage.setItem('catalog:mock-scenario', 'error')

// медленная сеть (2 с) для проверки скелетонов
localStorage.setItem('catalog:mock-scenario', 'slow')

// ошибка входа через провайдера
localStorage.setItem('catalog:mock-scenario', 'auth-error')

// сброс демо-сессии
localStorage.removeItem('catalog:session')
```

## 8. Диагностика

| Симптом | Причина | Решение |
|---|---|---|
| «Unable to locate file in Vite manifest» | Не выполнена сборка | `npm run build` |
| Страница пустая, в консоли `Failed to resolve component` | Не добавлен компонент shadcn-vue | `npx shadcn-vue@latest add <component>` |
| `Unknown file extension ".vue"` при тестах | В `vitest.config.js` нет `@vitejs/plugin-vue` | Добавить плагин и алиас `@` |
| Алиас `@` не разрешается | Нет `jsconfig.json` или `resolve.alias` в Vite | Проверить оба файла |
| `/admin` отдаёт SPA | Появился catch-all маршрут | Удалить `Route::fallback`/`{any}` из `routes/web.php` |
| Стили не совпадают с референсом | Токены темы не применены | Проверить CSS-переменные в `resources/css/app.css` и класс `dark` на `<html>` |
| Фильтры сбрасываются после F5 | Не работает гидратация из URL | Проверить `useCatalogQuery` и `catalogFilters.normalizeFilters` |
