## 2. Доступность (FR-033, SC-013)

| Проверка | Результат |
|---|---|
| `aria-label`/`aria-valuetext` у четырёх ручек слайдеров | Присутствуют: «Минимальная цена», «Максимальная цена», «Минимальный доход», «Максимальный доход»; значения в рублях |
| Связка `Label`/`Switch` «Проверен» | `label[for]` совпадает с `id` переключателя |
| Пагинация | `nav aria-label="Пагинация каталога"`, «Предыдущая страница»/«Следующая страница», номера «Страница N», `aria-current="page"` |
| Тост «Связаться» | `aria-live="polite"` (sonner) |
| Клавиатурный обход | `Tab` проходит: бренд → 3 пункта меню → VK → Yandex → 2 ручки цены → «Все зоны» → `.ru` → `.com` → `.de` → 2 ручки дохода → «Проверен» → «Применить» → «Связаться» → пагинация |
| Активация с клавиатуры | `Space` переключает зону, `Enter` применяет фильтры |
| Логотипы провайдеров | Декоративные (`aria-hidden`), смысл — в текстовой подписи/`aria-label` |

Для полного обхода зон клавишей `Tab` у `ToggleGroup` отключён roving focus (`:roving-focus="false"`); каждое значение зоны — отдельная кнопка в порядке табуляции.

Сверены тёмная палитра (`#191a1c` фон, `#1f2022` карточки, `#b9c94a` акцент), лаймовые акценты цены/кнопок, карточный список с сеткой `иконка → название/домен/описание → цена → доход → статус → проверка → кнопка`, шрифт Inter, hover-состояния карточек и кнопок.
