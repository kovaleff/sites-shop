# UI Contract: Личный кабинет продавца

**Feature**: `005-seller-cabinet` | **Date**: 2026-10-30 | **Тип**: внутренний контракт SPA

Описывает маршруты, экраны, состояния и взаимодействия. Источник данных — [`cabinet-api.yaml`](./cabinet-api.yaml); правила — `spec.md` и `data-model.md`. Стек: Vue 3.5 (JS, без TypeScript), Vue Router 4, Pinia 3, shadcn-vue + `reka-ui`, Tailwind 4.

---

## 1. Маршруты

| Путь | Имя | Компонент | Доступ |
|---|---|---|---|
| `/cabinet` | — | редирект на `/cabinet/sites` | авторизован |
| `/cabinet/sites` | `cabinet-sites` | `CabinetSitesView` | авторизован |
| `/cabinet/sites/new` | `cabinet-site-create` | `CabinetSiteFormView` (создание) | авторизован |
| `/cabinet/sites/:id/edit` | `cabinet-site-edit` | `CabinetSiteFormView` (редактирование) | авторизован |
| `/cabinet/hidden` | `cabinet-hidden` | `CabinetHiddenView` | авторизован |
| `/cabinet/messages` | `cabinet-messages` | `CabinetMessagesView` | авторизован |
| `/cabinet/messages/:id` | `cabinet-conversation` | `CabinetConversationView` | авторизован |

- `meta.requiresAuth = true` на всех маршрутах `/cabinet/*`.
- Глобальный `beforeEach`: если `session.isAuthenticated === false` и `session.isInitialized === false`, сначала `session.initialize()`; затем при отсутствии входа — тост «Войдите, чтобы открыть личный кабинет» и редирект на `/`.
- После входа `session.initialize()` повторно не выполняется; `redirect` на исходный адрес кабинета поддерживается через query `?redirect=` и не является обязательным для MVP.
- Сервер отдаёт SPA-shell для `/cabinet/*` без проверки входа (`view('app')`); данные приходят только из защищённых API.

- при выходе бейдж сбрасывается.

## 3. Экран «Мои объявления»

### Структура

```
CabinetLayout (навигация: Мои объявления | Сообщения | Скрытые)
└── CabinetSitesView
    ├── заголовок «Мои объявления» + кнопка «Добавить объявление»
    ├── SiteCard × 25
    │   ├── StatusBadge (Активен / Неактивен / Снят с продажи / Продан)
    │   ├── название, домен, зона
    │   ├── цена, доход, товарный знак
    │   ├── SubscriptionBlock: «Оплачено до …» + «Требует продления»
    │   ├── плашка «Скрыто из каталога» (если не публично)
    │   ├── VerificationBlock: имя файла + «Скопировать» + инструкция
    │   ├── «Сообщения: N» (если N > 0)
    │   └── действия: «Редактировать», «Сменить статус», «Скрыть» (только продан)
    └── Pagination (25 на страницу)
```

### Состояния

| Состояние | Отображение |
|---|---|
| Загрузка | 3 скелетона карточек, `aria-busy="true"` |
| Пусто | текст «У вас пока нет объявлений», кнопка «Добавить объявление» |
| Ошибка | текст ошибки и кнопка «Повторить» |
| Успех | карточки, счётчик «Показано N из M» |
| Пагинация за пределами | пустой список без ошибки |

### Действия

- «Добавить объявление» → `/cabinet/sites/new`.
- «Редактировать» → `/cabinet/sites/:id/edit`.
- «Сменить статус» открывает меню допустимых статусов (`availableStatuses`); выбор «Продан» показывает `alert-dialog` с подтверждением. Недоступные переходы не показываются.
- «Скрыть» доступно только для проданных: `alert-dialog` «Скрыть объявление из списка? История и переписка сохранятся». После успеха карточка исчезает из списка, тост «Объявление скрыто».
- Ошибки действий — тост с текстом из `message`.

## 4. Экран «Скрытые»

- Пустое состояние: «Скрытых объявлений нет».
- Пагинация 25.

## 5. Форма объявления

### Поля

| Поле | Компонент | Обязательно | Подсказка |
|---|---|---|---|
| Название | `input` | да | 3–255 символов |
| Домен | `input` (inputmode=url) | да | без `http://`, `www.`; дубликат отклоняется |
| Описание | `textarea` | да | 50–5000 символов, счётчик |
| Цена, ₽ | `input` (inputmode=numeric) | да | ≥ 0 |
| Месячный доход, ₽ | `input` (inputmode=numeric) | да | ≥ 0 |
| Товарный знак | `switch` | нет | — |
| Тематики | `select` множественный / список чекбоксов | да, ≥ 1 | данные из `/api/v1/categories` |

### Поведение

- Режим создания: заголовок «Новое объявление», кнопка «Сохранить»; после успеха — переход на `/cabinet/sites` и тост «Объявление создано».
- Режим редактирования: данные из `GET /my/sites/{site}`; поля `verified`, `verificationFilename`, `paidUntil` показаны только для чтения; для проданного объявления форма недоступна (редирект со списка).
- Ошибки 422 раскладываются по полям, под полем показывается первое сообщение; общий текст — тост.
- Пока запрос выполняется, кнопка «Сохранить» заблокирована и показывает «Сохраняем…»; повторная отправка невозможна.
- При 401 — тост «Войдите снова», введённые значения сохраняются в форме до перехода.
- После создания показывается блок «Файл проверки» с именем файла, кнопкой копирования и инструкцией (FR-010).

## 6. Экран «Сообщения»

### Список диалогов

- Строка: аватар собеседника, имя, название объявления, последнее сообщение (1 строка), время, бейдж непрочитанных.
- Сортировка: новые сверху; пагинация 25.
- Пусто: «Сообщения появятся, когда покупатели начнут писать по вашим объявлениям».
- Активный диалог выделен.

### Тред

- Сообщения по возрастанию времени; свои — справа, чужие — слева; время у каждого.
- При открытии вызывается `GET /conversations/{id}`, входящие помечаются прочитанными, бейдж в шапке и в списке уменьшается.
- Поле ввода + кнопка «Отправить», счётчик 0/2000; `Enter` отправляет, `Shift+Enter` — перенос строки.
- Режим «только чтение»: вместо поля — плашка с причиной («Объявление неактивно», «Снято с продажи», «Продано», «Подписка истекла»); кнопка отправки недоступна.
- Ошибка отправки: текст сохраняется, показывается тост, поле остаётся доступным.
- На мобильных список и тред — два экрана: `/cabinet/messages` и `/cabinet/messages/:id` (стрелка «Назад»).

## 7. Модальное окно «Связаться» (каталог)

- Компонент `ContactSellerDialog` монтируется в `CatalogView`; открывается по `@contact` от карточки, получает `listing`.
- Содержимое: название объявления, домен, `textarea` (0/2000), кнопки «Отправить» и «Отмена».
- Гость: вместо формы — текст «Войдите, чтобы написать продавцу» и кнопки входа (существующие обработчики VK/Яндекс); после входа окно закрывается.
- Свой лот: продавец не может открыть окно — кнопка «Связаться» на своей карточке в каталоге недоступна (лот не показывается в каталоге, так как он не публичный, если не оплачен; при оплаченном — показывается, но окно вернёт пояснение «Это ваше объявление»).
- Успех: окно закрывается, тост «Сообщение отправлено», каталог остаётся на той же странице с теми же фильтрами (URL не меняется).
- Ошибка 422 — сообщение под textarea; ошибка сети — тост, текст сохраняется.
- Доступность: фокус переходит в textarea при открытии, `Esc` закрывает окно, фокус возвращается на кнопку.

## 8. Общие состояния и ошибки

| Код | Поведение |
|---|---|
| 401 | стор сессии сбрасывается, тост «Войдите снова», редирект на `/` |
| 403 | не используется (чужие ресурсы → 404) |
| 404 | «Объявление не найдено» / «Диалог не найден», ссылка назад в кабинет |
| 422 | ошибки по полям + тост с общим текстом |
| 5xx | тост «Не удалось выполнить действие. Попробуйте ещё раз», кнопка повтора там, где есть |

Все экраны кабинета — адаптивные от 375 px; используются существующие токены и компоненты, отдельная тема не вводится.
